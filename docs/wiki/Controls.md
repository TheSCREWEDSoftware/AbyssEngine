# Controls

The default controls, for all classes. They can all be changed in **Options › Controls** ([Options](Options.md));
**Export** there writes this same page (`controls.md`) and keyboard (`controls-keyboard.svg`) for your own bindings,
next to `abyss.ini`.

**Esc** isn't bindable: it closes what's open, or opens the game menu (Options, leave, back to the game).

![Keyboard](controls-keyboard.svg)

Actions marked \* aren't in the engine yet.
