# 2. Getting the Source

**Installation guide:** [1. Requirements](01-Requirements.md) › **2. Getting the Source** › [3. Building](03-Building.md) › [4. Game Files](04-Game-Files-and-Configuration.md) › [5. First Run](05-First-Run.md)

Clone the repository:

```bash
git clone https://github.com/TheSCREWEDSoftware/AbyssEngine.git
cd AbyssEngine
```

> **Windows:** a short path without spaces (like `F:\AbyssEngine` or `C:\Dev\AbyssEngine`) avoids trouble with some
> build tools.

## Keeping up to date

```bash
git pull
```

The upstream project is [AbyssEngine/AbyssEngine](https://github.com/AbyssEngine/AbyssEngine). To also follow it:

```bash
git remote add upstream https://github.com/AbyssEngine/AbyssEngine.git
git fetch upstream
```
